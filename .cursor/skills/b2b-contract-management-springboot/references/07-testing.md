# 07 テスト戦略
## Backend
- JUnit 5 + Mockito: 状態遷移、承認経路、通知期限、金額、入力境界。
- 必須ケース: 申請で版固定・審査中編集 409、差戻し空コメント 400、差戻し→更新で新版→再申請は別 version_id、2段階は 2段目 WAITING・後続インボックス空・先回り 403、1段目承認後に 2段目 PENDING、取下げで DRAFT。
- Spring Boot Test + MockMvc: 400/401/403/404/409、DTO、権限、例外応答。
- Testcontainers PostgreSQL: JPAマッピング、Flyway、制約、検索、排他競合、トランザクション。
- ファイル保存・電子署名はモック/契約テストを分離。
## Frontend
- Vitest + Testing Library: 検索、フォーム、バリデーション、権限制御、競合時UI。
- Playwright: ウィザード起案→2段階申請→1段目承認→2段目インボックス→承認、または DEMO-RETURN-001 で再編集して新版再申請。
## 受入
- 未認可アクセス不可、二重承認不可、履歴改変不可、版固定、通知期限、障害復旧を確認。
- テスト未実行時は「未実行」と明記し、成功を偽装しない。
